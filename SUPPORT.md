# Support

Thanks for using HAventory! Here's where to go for help.

## Questions & how-to

- 💬 **[GitHub Discussions](https://github.com/chrreiter/HAventory/discussions)** —
  setup help, usage questions, and ideas.
- 📖 **[README](README.md)** and **[docs/](docs/)** — installation, the developer
  checklist, and the WebSocket API contract.
- 🏠 **[Home Assistant Community](https://community.home-assistant.io/)** — general
  HA and custom-integration discussion.

## Bugs & feature requests

- 🐛 **[Open an issue](https://github.com/chrreiter/HAventory/issues/new/choose)** —
  use the Bug report or Feature request form. Please search existing issues first.

## Security

- 🔒 Report vulnerabilities privately — see **[SECURITY.md](SECURITY.md)**. Do not
  file a public issue for security problems.

## Contributing

- 🛠️ Want to help build HAventory? See **[CONTRIBUTING.md](CONTRIBUTING.md)**.
